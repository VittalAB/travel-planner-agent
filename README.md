# Travel Agent

A travel-planning application built with a Python backend and a frontend.

## Overview

Use the application to explore travel-planning features through its frontend. The Python backend provides the server-side functionality and API.

## Run Locally

This README does not yet include setup commands. Install the dependencies and start the backend and frontend using the instructions in their respective project directories.

## Project Components

- **Backend:** Python server and API
- **Frontend:** User interface for the travel agent
